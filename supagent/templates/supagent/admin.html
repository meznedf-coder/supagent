Chat settings

LLM

An OpenAI-compatible chat API with tool calls. Authentication: none, a fixed access token, or a token from the company middleware (OAuth2 client credentials with the consumer key and secret, and a client certificate when the middleware asks for one), renewed before it expires.

Daily learning

Every day at the chosen hour, the metrics (promagg) and the indices (osagg) are read as the learning user: types, units, values, series, time ranges, relations, and what changed since the day before.

Knowledge search and memory

With each question the agent gets the knowledge that looks relevant: the dictionary, the catalog's notes and rules, the team's learned answers and memory, the documents. Words are searched with PostgreSQL's full-text search; with an embedding model (e.g. bge-m3 on the same gateway), meanings too. The vectors are kept in Superset's database (no extension, no service) or in a Qdrant server.

Team memory

Preferences, rules and facts for everyone, learned from the chats or written by users. Proposed ones are not used until an admin approves them. Approved rules and facts move into the catalog at the next learning run (setting learn.agent_catalog): edit them there.

Documents and sites

Documents the agent may search: text, Markdown or HTML files, and web pages read again every few days (a site: the pages under the same address). Only the allowed domains are read (setting docs.allowed_domains; empty: public sites only).

Catalog

What people know about the data, in separate entries: the glossary, one entry per index, groups of metrics, relationships, health checks, rules the agent always follows, notes, formulas. Each entry is saved on its own and keeps its history: a mistaken change or deletion can be restored.

The agent adds entries itself only on evidence it can check (setting learn.agent_catalog): formulas used in answers confirmed as helpful, team rules and facts an admin approved, definitions quoted word for word from the documents. They are marked agent; edit one to take it over, delete it and the agent never writes it again.
